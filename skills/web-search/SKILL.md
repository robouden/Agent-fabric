# Web Search Skill

## Capabilities
- **Search documentation** — find official docs for libraries and frameworks
- **Find best practices** — research industry-standard approaches
- **Compare options** — evaluate alternatives for a technical decision
- **Find examples** — locate code examples and tutorials

## Best Practices
1. Prefer official documentation over blog posts.
2. Check the date of sources — prefer recent content.
3. Cross-reference multiple sources for important decisions.
4. Cite sources when making recommendations.
5. Verify that recommended versions/APIs are still current.

## When to Use
- Evaluating technology choices.
- Finding the correct API usage for a library.
- Researching solutions to specific error messages.
- Comparing frameworks or tools.
