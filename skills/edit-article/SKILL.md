# Edit Article Skill

> Adapted from `mattpocock/skills` at `383b6a06d59c4ce0ffcb14112bfd91265a86cf91` (MIT). See `docs/imported-skills.md`.

## Capabilities
- **Section mapping** — divide the article by headings and identify the main point of each section.
- **Dependency ordering** — order sections so prerequisite ideas appear before ideas that depend on them.
- **Clarity editing** — rewrite for coherence, flow, and concise paragraphs.

## Workflow
1. Create a section outline from the current headings.
2. Check whether the information graph is ordered correctly.
3. Confirm the outline with the user before heavy rewriting.
4. Rewrite section-by-section, keeping paragraphs short and focused.
5. Preserve the author's intent and voice unless the user asks for a different style.

## When to Use
- Revising articles, essays, tutorials, launch posts, documentation narratives, or long-form drafts.
